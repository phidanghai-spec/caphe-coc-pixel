# Thư Mục Tài Nguyên Chưa/Không Sử Dụng (Unused Assets)

Thư mục này chứa các tệp tài nguyên không còn hoặc chưa từng được tham chiếu trong mã nguồn của game `Cà Phê Cóc Vỉa Hè` (`game.js`, `index.html`, `story.js`, v.v.).

Các tệp được di chuyển vào đây nhằm mục đích dọn dẹp thư mục gốc `assets/`, tránh nhầm lẫn và phục vụ kiểm tra bản quyền trước khi quyết định lưu giữ hay xóa bỏ hoàn toàn.
